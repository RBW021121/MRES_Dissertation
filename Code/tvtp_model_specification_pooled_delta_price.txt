
================================================================================
1. MEAN EQUATION (3-regime specification)
================================================================================

   y_it = mu_{S_it} + beta * position_it + epsilon_it,    epsilon_it ~ N(0, 1)

Where:
   y_it       = Delta retail price for station i at time t
   S_it       in {0, 1, 2}  regime state at observation (i,t)
   position_it = yesterday retail price - today's TGP
   beta       = Common effect of position in the mean equation

   Regime interpretations:
   - Regime 0: RELENTING (low-change state - competitive pricing response)
   - Regime 1: UNDERCUTTING (medium-change state - active competitive response)
   - Regime 2: NON-CYCLING (high-change / sticky state)


================================================================================
2. TIME-VARYING TRANSITION PROBABILITY (Multinomial Logit Form)
================================================================================

   P(S_it = j | S_i,t-1 = i, Z_it) = exp(Z_it' * gamma_ij) / Sum_k exp(Z_it' * gamma_ik)

Where:
   gamma_ij  = Transition parameters from regime i to regime j
   Z_it      = Exogenous variable vector (dimension: 3 x 1):
               Z_it = [1, ramp_t, ramp_t * I_brand]'

   ramp_t = Ramp variable:
            {0,                           if PUBLISH_DATE < 2022-06-01
            {(PUBLISH_DATE - June 1).days if PUBLISH_DATE >= 2022-06-01

   I_brand = Brand indicator (= 1 if major brand, 0 otherwise)


================================================================================
3. POOLED SAMPLE SPECIFICATION
================================================================================

   Unit of observation   | Station-day observation
   Sample structure      | Pooled across all stations
   Endogenous variable   | Delta retail price
   Mean exogenous var.   | position = yesterday price - tgp today
   TVTP exogenous vars.  | constant + ramp + ramp*brand
   Sample size           | All valid station-day observations in 2022

   This is a pooled Markov regression, not a median-aggregated daily model.


================================================================================
4. MODEL SPECIFICATION SUMMARY
================================================================================

   Component              | Specification
   -----------------------------------------------
   Endogenous variable    | Delta retail price
   Number of regimes      | 3
   Regime names           | Relenting, Undercutting, Non-cycling
   Mean exogenous var.    | Position
   Trend type             | Constant (intercept only)
   Exog. TVTP dimension   | 3 (constant + ramp + ramp*brand)
   Switching trend        | Yes (regime-specific intercepts)
   Switching variance     | Yes (regime-specific sigma2)
   Sample size            | Pooled station-day observations


================================================================================
5. REGIME INTERPRETATION
================================================================================

Regime 0: RELENTING
   - Retailers ease off aggressive price moves
   - Delta price tends to stabilize after previous adjustments

Regime 1: UNDERCUTTING
   - Retailers actively pressure rivals with pricing moves
   - Delta price reflects competitive discounting behavior

Regime 2: NON-CYCLING
   - Prices are sticky or remain elevated
   - Price changes are less cyclical and more persistent


================================================================================
6. KEY FEATURES
================================================================================

1. POOLED SPECIFICATION:
   - Uses all station-day observations rather than daily medians
   - Retains cross-sectional variation across stations

2. POSITION VARIABLE:
   - position = yesterday price - today's TGP
   - Captures station pricing relative to wholesale benchmark

3. RAMP VARIABLE:
   - Grows linearly from event date (June 1, 2022)
   - Captures time-dependent structural changes post-event
   - Allows transition probabilities to evolve dynamically

4. BRAND MODULATION:
   - ramp × brand interaction tests differential pricing response
   - Major brands (BP, Ampol, Coles, Puma, 7-Eleven) may respond differently
