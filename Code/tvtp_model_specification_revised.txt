
================================================================================
1. MEAN EQUATION (3-regime specification)
================================================================================

   y_t = mu_{S_t} + sigma_{S_t} * epsilon_t,    epsilon_t ~ N(0, 1)

Where:
   y_t        = Daily median margin at time t
   S_t        in {0, 1, 2}  regime state at time t

   Regime interpretations:
   - Regime 0: RELENTING (low-margin state - competitive pricing)
   - Regime 1: UNDERCUTTING (medium-margin state - competitive undercutting)
   - Regime 2: NON-CYCLING (high-margin state - price stickiness)


================================================================================
2. TIME-VARYING TRANSITION PROBABILITY (Multinomial Logit Form)
================================================================================

   P(S_t = j | S_{t-1} = i, Z_t) = exp(Z_t' * gamma_{ij}) / Sum_k exp(Z_t' * gamma_{ik})

Where:
   gamma_{ij} = Transition parameters from regime i to regime j
   Z_t        = Exogenous variable vector (dimension: 3 x 1):

                Z_t = [1, ramp_t, ramp_t * I_brand]'

   ramp_t = Ramp variable:
            {0,                           if PUBLISH_DATE < 2022-06-01
            {(PUBLISH_DATE - June 1).days if PUBLISH_DATE >= 2022-06-01

   I_brand = Brand indicator (= 1 if major brand, 0 otherwise)


================================================================================
3. EXOGENOUS TVTP SPECIFICATION
================================================================================

Pre-Event (Jan 1 - May 31, 2022):
   ramp_t = 0
   Z_t = [1, 0, 0]'
   --> Transition probabilities depend only on constant terms (baseline)
   --> Baseline regime dynamics (no brand effect)

Post-Event (Jun 1 - Dec 31, 2022):
   ramp_t = (PUBLISH_DATE - June 1).days  (ranges 0 to 214 days)
   Z_t = [1, ramp_t, ramp_t * I_brand]'
   --> Transition probabilities increase with time since event
   --> Brand-specific modulation through interaction term
   --> Major brands experience different transition rates than small brands


================================================================================
4. MODEL SPECIFICATION SUMMARY
================================================================================

   Component              | Specification
   -----------------------------------------------
   Endogenous variable    | Daily median margin (cents)
   Number of regimes      | 3
   Regime names           | Relenting, Undercutting, Non-cycling
   Trend type             | Constant (intercept only)
   Exog. TVTP dimension   | 3 (constant + ramp + ramp*brand)
   Switching trend        | Yes (regime-specific intercepts)
   Switching variance     | Yes (regime-specific sigma2)
   Sample size            | 365 days (2022)


================================================================================
5. REGIME INTERPRETATION
================================================================================

Regime 0: RELENTING
   - Interpretation: Retailers retreat from aggressive pricing
   - Pricing dynamic: Price cuts followed by slow recovery
   - Market state: Competitive pressure easing

Regime 1: UNDERCUTTING
   - Interpretation: Active price competition among retailers
   - Pricing dynamic: Continuous downward pressure on margins
   - Market state: Margin compression phase

Regime 2: NON-CYCLING
   - Interpretation: Prices sticky, limited competition
   - Pricing dynamic: High margins maintained without frequent adjustments
   - Market state: Collusive or coordinated pricing


================================================================================
6. KEY FEATURES
================================================================================

1. RAMP VARIABLE:
   - Grows linearly from event date (June 1, 2022)
   - Captures time-dependent structural changes
   - Allows transition probabilities to evolve dynamically post-event

2. BRAND MODULATION:
   - ramp × brand interaction tests differential pricing response
   - Major brands (BP, Ampol, Coles, Puma, 7-Eleven) may respond differently
   - Smaller/independent stations face different competitive pressures

3. REGIME DYNAMICS:
   - Transition probabilities vary smoothly over time
   - Event activates ramp variable at t = June 1
   - Pre-event: constant-only transition probabilities
   - Post-event: time- and brand-dependent transitions
