
================================================================================
1. MEAN EQUATION (2-regime specification)
================================================================================

   y_it = mu_{S_it} + beta_1 * position_it + beta_2 * Major_it + beta_3 * position_it * Major_it + epsilon_it,
   epsilon_it ~ N(0, 1)

Where:
   y_it        = Delta retail price for station i at time t
   S_it        in {0, 1}  regime state at observation (i,t)
   position_it = yesterday retail price - today's TGP
   Major_it    = 1 if station i is a major brand, 0 otherwise

   Regime interpretations:
   - Regime 0: lower-change / more responsive state
   - Regime 1: higher-change / more persistent state


================================================================================
2. TIME-VARYING TRANSITION PROBABILITY (Multinomial Logit Form)
================================================================================

   P(S_it = j | S_i,t-1 = i, Z_it) = exp(Z_it' * gamma_ij) / Sum_k exp(Z_it' * gamma_ik)

Where:
   gamma_ij  = Transition parameters from regime i to regime j
   Z_it      = Exogenous variable vector (dimension: 4 x 1):
               Z_it = [1, position_it, ramp_t, ramp_t * position_it]'

   ramp_t = Ramp variable:
            {0,                           if PUBLISH_DATE < 2022-06-01
            {(PUBLISH_DATE - June 1).days if PUBLISH_DATE >= 2022-06-01


================================================================================
3. POOLED SAMPLE SPECIFICATION
================================================================================

   Unit of observation   | Station-day observation
   Sample structure      | Pooled across all stations
   Endogenous variable   | Delta retail price
   Mean exogenous vars.  | position + Major + position*Major
   TVTP exogenous vars.  | constant + position + ramp + ramp*position
   Sample size           | All valid station-day observations in 2022

   This is a pooled Markov regression, not a median-aggregated daily model.


================================================================================
4. MODEL SPECIFICATION SUMMARY
================================================================================

   Component              | Specification
   -----------------------------------------------
   Endogenous variable    | Delta retail price
   Number of regimes      | 2
   Regime names           | Lower-change, Higher-change
   Mean exogenous vars.   | Position, Major, Position*Major
   Trend type             | Constant (intercept only)
   Exog. TVTP dimension   | 4 (constant + position + ramp + ramp*position)
   Switching trend        | Yes (regime-specific intercepts)
   Switching variance     | No
   Sample size            | Pooled station-day observations


================================================================================
5. REGIME INTERPRETATION
================================================================================

Regime 0: LOWER-CHANGE
   - Delta price is smaller or more responsive to position
   - Captures the more adjustment-prone state

Regime 1: HIGHER-CHANGE
   - Delta price is larger or more persistent
   - Captures the more stable / elevated-change state


================================================================================
6. KEY FEATURES
================================================================================

1. POOLED SPECIFICATION:
   - Uses all station-day observations rather than daily medians
   - Retains cross-sectional variation across stations

2. POSITION VARIABLE:
   - position = yesterday price - today's TGP
   - Captures station pricing relative to wholesale benchmark

3. RAMP VARIABLE:
   - Grows linearly from event date (June 1, 2022)
   - Captures time-dependent structural changes post-event
   - Allows transition probabilities to evolve dynamically

4. BRAND MODULATION:
   - Major brand indicator and position interaction enter the mean equation
   - Major brands may have different delta-price responses to position
